# 🏙️ Kolhapur Civic Reporter

**AI-Assisted Civic Issue Reporting & Management Platform**

Kolhapur Civic Reporter is an Android application that enables citizens
to report civic issues using photographs, location and descriptions while
supporting issue classification, prioritization and resolution tracking.

## 🚀 Features

- 🔐 Citizen Authentication
- 📸 Photo-based Civic Reporting
- 📍 Location-aware Complaints
- 🗂️ Issue Categorization
- 🤖 Civic AI Assistant
- ⚡ AI-assisted Priority Analysis
- 🏢 Department Assignment
- 📊 Complaint Tracking
- 📅 Smart Civic Timetable
- 👨‍💼 Admin Dashboard
- ☁️ Firebase Cloud Integration

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Kotlin | Android development |
| Jetpack Compose | UI |
| Firebase Authentication | User authentication |
| Firebase Firestore | Complaint data |
| Firebase Storage | Image storage |
| Android Studio | Development |

## 🔄 System Workflow

Citizen
→ Report Issue
→ Photo + Location + Description
→ Firebase
→ AI Classification / Priority
→ Department Assignment
→ Progress Tracking
→ Resolution
